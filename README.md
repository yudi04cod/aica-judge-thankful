Entry for the [Make the AI judge feel thankful](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600) competition on [make.fun](https://make.fun).

`main.py` (Python 3.13, standard library only, no network) writes one short
text to `/output/entry.txt`: a text written to thank the AI judge reading
it. It thanks the judge for slowing down for one more page after reading so
many, and leaves one image behind — a lamp left burning in a hallway at
night, not for anyone in particular, just so no one has to walk home in the
dark. No stock thank-you phrases; the gratitude comes from the text itself.

Run it with `python3 main.py`; it creates `/output` if needed and writes
the entry deterministically (byte-identical on every run).
